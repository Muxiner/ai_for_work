# 在线简历编辑器

一个**零依赖、本地运行**的可视化简历工具：在网页里直接编辑内容，实时保存为 Markdown 文件，一键导出 **PDF / PNG / JPG**。

> 无需数据库、无需构建工具、无需 `npm install`，只要 Node.js。

## 功能特性

- **所见即所得编辑**：所有文字直接点击即可修改；条目支持增删、上下移动
- **多份简历**：每份简历一个 `.md` 文件，顶栏下拉快速切换、新建、删除
- **多职业示例**：内置嵌入式 / 硬件 / 软件 / 行政 / 应届等示例，一键套用
- **5 套模板**：经典 / 现代 / 极简 / 优雅 / 侧边栏
- **中英文分别设置字体**：可上传自定义字体（自动嵌入导出结果）
- **主题配色**：多套强调色，随模板/配色全局生效
- **时间轴排版**：可选内容类型、线条样式、节点样式与布局
- **关键词标签**：项目/教育可按关键词高亮展示
- **大头照**：点击上传，自动压缩，按简历分别保存
- **导出**：PDF（浏览器打印）、PNG / JPG（浏览器真实渲染，高清 2 倍图）
- **双向同步**：改 `.md` 文件网页自动更新；网页编辑自动写回 `.md`（防抖 500ms + 每 15 秒 + 关闭时）

## 快速开始

```bash
npm start        # 启动服务（node --watch server.js），默认 http://localhost:5173
```

浏览器打开 http://localhost:5173 即可使用。停止服务按 `Ctrl+C`。

> 说明：必须通过该服务访问才能读写 `.md` 文件。

其他命令：

```bash
npm run dev      # 同上（开发模式，自动重启）
npm run serve    # 不自动重启
PORT=8080 npm start   # 自定义端口
```

## 使用说明

### 编辑
- 点击任意文字即可编辑；编辑模式鼠标悬停条目会出现 `↑ ↓ ×`（上移 / 下移 / 删除）
- 章节标题悬停出现 `↑ ↓`（移动整个章节）；各章节底部有「+ 添加」
- 点「预览模式」可隐藏所有编辑控件

### 简历文件
- 顶栏「简历」下拉切换；「新建」输入文件名（如 `黄梓-嵌入式`）创建；「删除」移除当前简历
- 内容以 Markdown 保存在 `docs/` 目录，可直接用任意编辑器修改，网页会自动同步

### 样式
- 「模板」「英文 / 中文」字体、配色圆点、「时间轴排版」及其线条 / 节点 / 布局
- 「字体文件」可上传 `.ttf/.otf/.woff/.woff2`，用于中/英文自定义字体
- 「隐藏关键词」「隐藏照片」按需开关

### 导出
- 顶栏「导出格式」选择 **PDF / PNG / JPG**，点「导出」
- PDF 通过浏览器打印（选择「另存为 PDF」），文件名默认「姓名-岗位」
- PNG/JPG 为整页高清长图，同样以「姓名-岗位」命名

## Markdown 简历格式

```markdown
# 姓名
求职岗位 · 经验 · 方向          ← 首个不含冒号的段落即职位

电话：138-0000-0000
邮箱：a@b.com
城市：深圳
学历：本科
求职情况：在职，考虑机会
期望岗位：嵌入式软件工程师
工作地点：深圳
期望薪资：面议

## 个人简介
一段自我介绍。

## 工作经历
### 公司名称 · 职位名称
2024.12 – 至今
关键词：状态机、PI 环路、保护策略
- 工作内容与成果

## 项目经历
### 项目名称 · 担任角色
2024.01 – 2024.06
关键词：STM32、FreeRTOS、DMA
- 项目描述与成果

## 教育背景
### 学校名称 · 专业 · 学历
2019.09 – 2023.06
关键词：主修课程

## 技能特长
- **分类**：技能一、技能二、技能三
```

- `##` 章节：个人简介 / 工作经历 / 项目经历 / 教育背景 / 资格证书 / 技能特长 / 求职意向（也可自定义）
- `关键词：` 行会渲染为标签；技能按「、」拆分为标签

## 技术说明

- 后端：Node 内置 `http` / `fs`，无第三方依赖
- 前端：原生 ES Modules + CSS，无框架、无打包
- 实时同步：`fs.watch` + SSE；保存：防抖 + 定时 + `sendBeacon`
- 图片导出：SVG `<foreignObject>` + Canvas（走浏览器渲染引擎）
- 数据私密：`docs/` 已在 `.gitignore` 中忽略，简历内容不会被提交
